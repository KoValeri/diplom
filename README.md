# Recipes App

A SPA application for displaying a list of recipes and detailed information about each recipe.
The data is fetched from the DummyJSON API.

## Features
- React 19 with hooks
- React Router DOM for routing
- Redux Toolkit for state management
- RTK Query for caching and working with APIs
- Node.js v22 and Express.js for work with DB
- MSSQL to create DB

## Pages
- Home page with slider, setcinons for sales, new books and top sales
- Detail page for every book
- Auth forms with validation logic
- Page for cart, orders and favorite positions
- Admin logic

## Technical Features
- Fetch data from DB
- View details
- Adding books in favorites list
- Searching and filtration
